# MediFast COD & Settlement Model

## Status

Implemented and verified on 2026-06-03.

---

# Cash Flow

Customer pays cash on delivery.

```text
Customer
    ↓
Driver
    ↓
Vendor
```

Vendor settles with MediFast periodically.

---

# Delivery Economics

## Customer Delivery Fee

Fixed delivery fee:

```text
7 LYD
```

Applied server-side using:

```sql
public.calculate_delivery_fee(distance_km)
```

Current implementation returns:

```text
7.00
```

for all valid deliveries.

Delivery settings are stored in:

```sql
public.platform_settings
```

Current delivery settings:

```json
{
  "base_fee": 7,
  "per_km_fee": 0,
  "max_radius_km": 15
}
```

---

# Delivery Radius

Platform maximum radius:

```text
15 km
```

Vendor default radius:

```text
15 km
```

Vendor-specific radius:

Uses `vendors.delivery_radius_km` when present.

Current checkout enforcement uses:

```text
least(vendor delivery radius, platform max radius)
```

Orders outside the permitted radius are rejected during checkout.

Enforced in:

```sql
public.create_cod_order()
```

---

# Driver Compensation

Driver payout:

```text
7 LYD per completed delivery
```

Current MVP assumption:

```text
Customer pays driver
Driver keeps 7 LYD
Driver transfers remaining funds to vendor
```

Driver settlements are currently handled operationally outside the system.

---

# Vendor Economics

Vendor commission:

```text
5%
```

Additional MediFast delivery margin:

```text
3 LYD per delivered order
```

---

# Vendor Settlement Formula

Settlement includes only orders where:

```text
order_status = delivered
payment_status = collected
```

Formula:

```text
Gross Sales
− Vendor Commission
− Delivery Margin
= Net Vendor Amount
```

Implemented in:

```sql
public.calculate_vendor_settlement()
```

---

# Example

Medicine subtotal:

```text
123.09 LYD
```

Commission:

```text
5%
= 6.15 LYD
```

Delivery margin:

```text
3.00 LYD
```

Net vendor amount:

```text
123.09
− 6.15
− 3.00
= 113.94 LYD
```

Verified result:

```text
gross_sales = 123.09
commission_amount = 6.15
delivery_margin_amount = 3.00
net_amount = 113.94
```

# COD Payment Collection

When driver marks order:

```text
on_the_way
→ delivered
```

System automatically updates:

```text
payment_status
pending → collected
```

for:

```text
payment_method = cash_on_delivery
```

Implemented in:

```sql
public.driver_update_order_status()
```

---

# Settlement Lifecycle

1. Customer places order.
2. Vendor prepares order.
3. Driver claims order.
4. Driver delivers order.
5. COD payment marked collected.
6. Settlement generated by admin.
7. Settlement optionally marked paid.

Settlement statuses:

```text
pending
paid
```
